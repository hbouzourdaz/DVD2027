# مكتبة محتوى DVD2027

موقع ثابت (HTML + Tailwind CSS) يعمل كمكتبة تفاعلية لتنظيم وفلترة محتوى مجلد `E:\DVD2027` (دروس، امتحانات، مذكرات، ملخصات، كتب ومراجع...). جاهز للرفع المباشر على Vercel.

## المميزات

- تصفح هرمي: المجلدات الرئيسية ← الفرعية ← ... ← الملف، مع شريط تنقّل (Breadcrumb).
- بحث فوري في أسماء الملفات والمسارات.
- فلترة حسب: الفئة، السنة/القسم (1م/2م/3م/4م)، الموضوع، الامتداد.
- فرز حسب الحجم والاسم والتاريخ.
- إحصائيات عامة وتوزيع الفئات (رسوم بيانية).
- تصميم متجاوب RTL مع ثيم داكن/فاتح قابل للتبديل.
- روابط «فتح الملف» تعمل مباشرة لأن الملفات موجودة فعلياً في `files/`.

## ملفات المشروع

```
E:\DVD2027\
├─ index.html            الموقع كاملاً (ملف واحد + Tailwind CDN)
├─ data.js               بيانات الملفات (يُحمَّل مباشرة — يعمل حتى بدون خادم)
├─ data.json             نسخة JSON من البيانات (للأدوات/المرجع)
├─ scripts/generate-data.js   يولّد data.js و data.json من E:\DVD2027\files
├─ files/                محتوى الملفات الفعلي (بنية المجلدات الأصلية)
└─ README.md
```

## إعادة توليد البيانات

قاعدة بيانات الموقع هي مجلد المحتوى `E:\DVD2027\files` نفسه، وتُقرأ مباشرة منه (قراءة فقط). لتحديث البيانات بعد أي إضافة/تعديل:

```
node scripts/generate-data.js
```

السكربت يقوم بما يلي تلقائياً:
- يمسح `E:\DVD2027\files` تكرّرياً ويقرأ أسماء الملفات وخصائصها فقط.
- يتجاهل الملفات المخفية/النظامية و `.gitkeep` والاختصارات (لا يتتبّع الروابط خارج المجلد).
- يحدّث `data.js` و `data.json` مباشرة.

## التجربة محلياً

```
npx serve E:\DVD2027
```

ثم افتح `http://localhost:3000` (روابط «فتح الملف» تعمل هنا).

## الرفع على Vercel

> تنبيه الحجم: محتوى `files/` يبلغ ~9 GB، وهذا يتجاوز حد مشاريع Vercel المجانية. الحلول العملية:
> - ارفع الموقع (دون `files/`) أولاً ليعرض الفهرس والفلترة، ثم ارفع الملفات على دفعات حسب الأولوية.
> - أو استخدم خططاً تسمح بحجم أكبر (Business/Enterprise).

### الخيار 1 — GitHub (أسهل)
1. ارفع الملفات (باستثناء `files/` أو أجزاء منها) إلى مستودع GitHub.
2. على vercel.com: **Add New → Project → Import** المستودع.
3. لا حاجة لأي إعدادات (Framework Preset: **Other**، Output Directory: **/**).
4. اضغط **Deploy**.

### الخيار 2 — سطر الأوامر
```
npm i -g vercel
cd E:\DVD2027
vercel --prod
```

## الروابط بعد النشر

أي ملف داخل `files/` يُخدَّم تلقائياً على المسار `https://موقعك/files/<المسار النسبي>` وتشتغل روابطه من المكتبة مباشرة.
